AtlasOS

AtlasOS is a command-line shell written in Python for learning purposes. It simulates the basic behavior of an operating system shell while providing a modular architecture and a set of built-in commands.

«Disclaimer: AtlasOS is not a real operating system. It is a terminal-based application designed to practice software architecture, Python programming, and SQLite.»

---

Features

- User authentication
- Interactive command-line shell
- Modular command system
- Built-in help command
- Terminal clear command
- Date and time commands
- About command
- Calculator
- Notes management using SQLite
- Unknown command handling
- Clean project structure

---

Technologies

- Python 3
- SQLite
- Modular programming
- Command Line Interface (CLI)

Installation

Clone the repository:

git clone https://github.com/<your-username>/AtlasOS.git

Navigate to the project folder:

cd AtlasOS

Run AtlasOS:

python main.py

---

Available Commands

Command| Description
help| Display all available commands
clear| Clear the terminal
about| Display information about AtlasOS
date| Display the current date
time| Display the current time
calc| Open the calculator
notes| Manage notes stored in SQLite
exit| Exit AtlasOS
